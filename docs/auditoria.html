      1. Resumo executivo

      O Flix é dois produtos no mesmo app Next.js 16: a biblioteca em / organiza YouTube pessoal (categorias, coleções, histórico) e o catálogo em /catalogo é a vitrine paga do criador (arquivo no disco, player autenticado, paywall por plano). Desde a auditoria de 15 set 2026 o produto ganhou trilha didática: Course / módulos / aulas, admin em /admin/cursos e sala em /catalogo/cursos/[slug]. PIX continua manual. Não há motivo para reescrever.

      O achado que muda a prioridade continua sendo o mesmo da auditoria anterior, agora acompanhado de vazamento de infra: o README e o POST de criação/upload dizem que só admin publica, mas PATCH/DELETE/grants de /api/catalog/[id] aceitam o dono do vídeo. A UI esconde o botão “Publicar” do header e mostra Publicar/Despublicar em todo card mine. Em paralelo, .gitignore força o versionamento de .env.production e GET /api/health devolve host do banco, probes e migrate sem autenticação.

      Cursos, FFmpeg, cron de cobrança, LGPD (export + anonimizar), CSRF e rate limit MySQL já existem. Prisma 5 e NextAuth v4 estão pinados de propósito. O plano aprovado em 18 set 2026 fecha segurança e vitrine, depois confirma InnoDB em ConsentimentoLgpd e UX pontual — sem Stripe, HLS nem shell WMS.

      3. Funcionalidades já implementadas

      Clube do criador

      Upload em /admin/videos e POST admin em /api/catalog + /api/catalog/upload (MP4/WebM/MOV até 3 GB, magic-bytes). Plano mínimo por vídeo. Stream privado com Range, ETag e private, no-cache. Visitante free; assinante vê conforme o plano. Grants extras. Favorito e progresso por usuário.

      Cursos

      Course agrupa módulos e aulas (1:1 com Video, inclusive source=article). Admin monta currículo em /admin/cursos/[id] com drag-and-drop. Assinante entra em /catalogo/cursos/[slug] (landing + sala). Apagar o curso não apaga o arquivo — só a trilha.

      Cobrança e operação

      /plano pede upgrade, mostra PIX, envia comprovante. Admin aprova em /admin/solicitacoes, registra pagamento, renova / cancela. Cron diário de vencimento. Auditoria, CSV, health, LGPD (export JSON + anonimizar). CSRF de Origin em /api/*. Rate limit MySQL em login/cadastro/recuperação.

      Biblioteca pessoal

      / é organizador de YouTube: categorias, notas, coleções com link /c/[token], histórico, estatísticas, cota por plano. POST /api/videos cria só source=youtube.

      4. Problemas encontrados

      Crítico .env.production versionado

      Onde: .gitignore:37-40 (!.env.production).

      O que é: a exceção do gitignore manda o arquivo de produção para o repositório. Catálogo git-segredo-em-arquivo-local. O conteúdo não foi aberto nesta auditoria.

      Impacto: se o arquivo tiver NEXTAUTH_SECRET, DATABASE_URL, CRON_SECRET ou RESEND_API_KEY reais, qualquer clone lê os segredos.

      Solução: remover a exceção, git rm --cached .env.production, rotacionar segredos se já vazaram. Complexidade baixa.

      Alto Dono não-admin publica e apaga no catálogo

      Onde: app/api/catalog/[id]/route.ts PATCH/DELETE; lib/video-grants.ts loadManagedCatalogVideo; app/catalogo/page.tsx ações em v.mine; grants em app/api/catalog/[id]/grants/route.ts.

      O que é: POST create/upload exige requireAdmin. PATCH/DELETE/grants aceitam qualquer dono. README: “Assinante não publica no catálogo.” Mesmo achado de 15 set, ainda aberto. Mutações também não chamam logAdminAction.

      Impacto: a loja deixa de ser só do criador.

      Solução: requireAdmin() + auditoria + esconder ações de card para não-admin. Complexidade baixa.

      Alto /api/health público vaza infra

      Onde: app/api/health/route.ts:6-40.

      O que é: sem auth; devolve dbHost, probes e resultado de migrate.

      Impacto: mapeamento da topologia MySQL e do estado das migrations para qualquer visitante.

      Solução: responder só status + database (+ timestamp). Complexidade baixa.

      Alto Busca de usuários devolve e-mail e plano a qualquer logado

      Onde: app/api/users/search/route.ts:9-40. Cliente: UserPicker (grants do catálogo / admin). Biblioteca compartilha por e-mail digitado, não por essa rota.

      Impacto: enumeração de contas e planos.

      Solução: requireAdmin(). Complexidade baixa.

      Médio ConsentimentoLgpd pode estar MyISAM sem FK no live

      Onde: comprovado em 15 set no information_schema; migration 20260916090000_lgpd_soft_delete declara InnoDB+FK. Reconsultar o banco nesta execução.

      Impacto: consentimento órfão se houver hard-delete. O app anonimiza User, então hoje não explode.

      Solução: ALTER TABLE ... ENGINE=InnoDB + recriar FK se a query confirmar. Complexidade baixa.

      Médio Signup 500 devolve código Prisma

      Onde: app/api/auth/setup/route.ts:74-79.

      Impacto: o cliente vê P2021 e similares. Solução: logar no servidor, não no JSON. Complexidade baixa.

      Baixo CollectionVideo.addedBy sem FK

      Onde: prisma/schema.prisma model CollectionVideo. Impacto: integridade frouxa. Adiar; não bloqueia venda.

      Baixo Miniatura publicada sem paywall

      Onde: app/api/videos/[id]/thumbnail/route.ts — visitante vê thumb se published; cache público. O stream continua paywalled. Decisão de produto: manter como preview da vitrine.

      Baixo Remover módulo/aula sem ConfirmDialog

      Onde: app/components/admin/courses/ModuleCard.tsx. O curso inteiro já confirma. Catálogo ui-exclusao-sem-confirmacao.
